Technical Terms

RAM
Random Access Memory used for temporarily storing data while programs are running.
SSD
Solid State Drive used for fast permanent data storage.
CPU
Central Processing Unit responsible for executing computer instructions.
GPU
Graphics Processing Unit used for graphics and parallel computing tasks.
Refresh Rate
The number of times a display refreshes its image per second, measured in Hz.
Battery Capacity
The amount of electrical energy a laptop battery can store.
